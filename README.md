# Saját AI-eszközök — kurzusoldal

Az Eötvös József Collegium Gazdaságtudományi műhelyének AI-kurzusa (2027 tavasz). Quarto-weboldal, GitHub Pages-en.

- `index.qmd`, `tematika.qmd`, `projekt.qmd` — a kurzusoldal lapjai
- `telepites/` — önálló HTML-útmutató a programok telepítéséhez (nem renderelődik, csak bemásolódik); a `gepcsekk.py` az oldalba ágyazott kód másolata, a kettőt együtt kell módosítani
- `styles/` — világos és sötét téma (EJC-navy és -arany)

Helyi előnézet: `quarto preview`. Élesítés: push a `main` ágra, a GitHub Actions rendereli és kiteszi.

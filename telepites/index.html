Mi mire való?

Öt dolgot telepítesz, de a félév során szinte mindig csak egy ablakot fogsz látni: a VS Code-ot. A többi program a háttérben dolgozik.

VS Code

a munkaasztal

Kódszerkesztő program. Ebben nyitod meg a projekt mappáját, itt olvasod és írod a fájlokat, és itt fut a terminál és az AI-asszisztens is.

Olyan, mint pl. a Word, csak programkódhoz és egész mappákhoz.

Python

a motor

A programozási nyelv, és a program, amely lefuttatja a Pythonban írt kódot. Nélküle egy .py fájl csak szöveg, nem csinál semmit.

Az Excelben a képlet csak akkor ad eredményt, ha az Excel kiszámolja. A Python a "kódot számolja ki".

Git

a verziókövető

Pillanatképeket ment a projekt mappájáról. Minden pillanatképhez (commit) egy rövid leírás tartozik, és bármelyikhez vissza lehet ugrani.

Olyan, mint a Wordben a változások követése/előző verziók, csak az egész mappára, és sosem veszik el.

GitHub

a felhő

Weboldal, ahol a Git-pillanatképek a neten is megvannak. Innen fogod beadni a projektet, itt dolgozhatsz együtt másokkal, és ezzel a fiókkal lépsz be a Copilotba.

Olyan, mint a Google Drive, csak Git-projektekhez.

GitHub Copilot (és opcionálisan Claude Code)

az AI-asszisztens

A VS Code-ba épülő AI-asszisztens. Látja a projekt fájljait, akár magyarul is megkérheted, hogy írjon kódot vagy futtasson parancsot, és a félév során végig ezzel dolgozunk. A kódot ő írja, te pedig elolvasod és ellenőrzöd. Ehhez tanulunk csak annyi Pythont, amennyi kell.

Olyan, mint egy gyors, szorgalmas gyakornok. Hihetetlen sokat dolgozik, de az eredményét mindig át kell nézni.

Te→kérsz az asszisztenstől→ő kódot ír→a Python lefuttatja→te ellenőrzöd→a Git elmenti→a GitHubra feltöltöd
1

GitHub-fiók és hallgatói igazolás

⏱ 15 perc + néhány nap várakozásböngészőben

Ezzel kezdd, mert a hallgatói igazolás elbírálása napokig is eltarthat.

  1. Nyisd meg a github.com/signup oldalt, és add meg az e-mail-címed, egy jelszót és egy felhasználónevet.

    Felhasználónév: legyen komoly, mert később ez fog szerepelni a projektjeid webcímében is (pl. github.com/tuboly-roland). Az e-mail-cím lehet a magáncímed. Az egyetemit a következő lépésben adod hozzá.

  2. Erősítsd meg az e-mail-címed (a GitHub kódot küld), majd kapcsold be a kétlépcsős azonosítást. A GitHub úgyis kérni fogja. Egy hitelesítő app kell hozzá a telefonodra (pl. Google Authenticator vagy Microsoft Authenticator).

    Mentsd el a helyreállító kódokat (recovery codes), amiket a GitHub a beállítás végén mutat. Ha elveszíted a telefonod, csak ezekkel tudsz visszalépni.

  3. A profilodban (Settings → Public profile) írd be a teljes neved úgy, ahogy a diákigazolványodon szerepel. Az Emails oldalon add hozzá és erősítsd meg az egyetemi e-mail-címed is.

  4. Nyisd meg a github.com/settings/education/benefits oldalt, kattints a Start an application gombra, válaszd a Student lehetőséget, és keresd ki az egyetemedet (ELTE).

  5. Igazolásként tölts fel egy fényképet az érvényes diákigazolványodról, vagy a Neptunból letöltött hallgatói jogviszony-igazolásról. Mindkettőn látszódjon a neved, az egyetem neve és az aktuális félév.

    Ami miatt a legtöbb kérelmet elutasítják: elmosódott fotó; bekapcsolt VPN vagy letiltott helymeghatározás (a GitHub ellenőrzi, honnan jelentkezel, ezért ha a böngésző kéri, engedélyezd); eltérő név a profilban és az igazoláson; felvételi határozat jogviszony-igazolás helyett.
Mi történik ezután? A GitHub általában néhány napon belül e-mailben válaszol. Ha elfogadják, ingyen megkapod a Copilot Student csomagot, de az aktiválás még pár napot vehet igénybe. Ha az első óráig nem érkezik meg, az sem baj: addig az ingyenes Copilot Free csomaggal dolgozunk.

VS Code telepítése

⏱ 10 perckb. 400 MB

A munkaasztal. Ezt telepítjük másodikként, mert a Python és a Git ellenőrzéséhez már a VS Code beépített terminálját használjuk.

  1. Nyisd meg a code.visualstudio.com/download oldalt, és töltsd le a gépednek megfelelő változatot.

  2. Futtasd a letöltött VSCodeUserSetup-….exe fájlt. Fogadd el a licencet, a következő képernyőkön maradhat minden alapértelmezett, kivéve az Additional Tasks oldalt. Ott pipáld be ezt a hármat:

    • Add "Open with Code" action to Windows Explorer file context menu
    • Add "Open with Code" action to Windows Explorer directory context menu
    • Add to PATH (alapból be van pipálva, maradjon is így)

    Így egy mappára jobb gombbal kattintva közvetlenül megnyithatod a VS Code-ban.

  3. Nyisd meg a letöltött ZIP-fájlt (ha a Safari nem csomagolta ki magától), és a Visual Studio Code alkalmazást húzd át a Finderben az Alkalmazások (Applications) mappába. Ezután onnan indítsd el. Az első indításnál a macOS megkérdezi, biztosan megnyitod-e: Megnyitás.

  4. A VS Code-ban nyomd meg a ⌘ ⇧ P billentyűket. Ez a command palette, a VS Code „mindent-kereső” mezője. Írd be, hogy shell command, és válaszd az Install 'code' command in PATH sort.

  5. Lehet hogy hozzáférést/jelszót fog kérni, ezeket add meg/írd be, majd telepítsd a Python-bővítményt. Bal oldalt a függőleges menüsorban kattints a négy kis négyzetből álló Extensions ikonra (vagy Ctrl⌘ ⇧ X), keresd meg a Python bővítményt, és kattints az Install gombra annál, amelyiknek a kiadója a Microsoft (kék pipa jelzi).

    Más bővítményt most ne telepíts. A Copilot már benne van a VS Code-ban, azt az 5. lépésben kapcsoljuk be.

Elindul a VS Code, és látod a bal oldalt a Python-bővítményt az Extensions listában?

Python telepítése

⏱ 10 percpython.org, 3.14-es verzió

A motor. A hivatalos python.org oldalról telepítjük. Ha valahol már van Pythonod (pl. Anaconda), az sem baj, de a kurzushoz telepítsd ezt is kérlek.

  1. A python.org/downloads oldalon kattints a sárga Download Python install manager gombra.

  2. Nyisd meg a letöltött python-manager-….msix fájlt, és kattints az Install (Telepítés) gombra. Ez a Python-telepítő segédprogramját teszi fel, magát a Pythont a következő lépésben töltjük le.

  3. Indítsd újra a VS Code-ot, és nyiss egy terminált: felső menü Terminal → New Terminal (vagy Ctrl `). Alul megjelenik egy sor, ami PS C:\Users\…> kezdetű. Ide gépeld be, majd nyomj Entert:

    py install 3.14

    Ha a terminál kérdez valamit (például hogy felvegye-e a parancsokat a PATH-ba), írj y-t, és nyomj Entert.

  4. Zárd be a terminált (a kuka ikonnal a jobb oldalán), nyiss egy újat, és ellenőrizd:

    python --version
Python 3.14.8
    Ha a Microsoft Store nyílik meg, vagy azt írja, hogy a „python” nem található, nézd meg a Ha elakadsz rész első pontját.

  1. A python.org/downloads oldalon kattints a sárga Download Python 3.14.x gombra. Egy .pkg fájlt kapsz.

  2. Nyisd meg a .pkg fájlt, és kattints végig: Folytatás → Elfogadom → Telepítés. A gép jelszavát kérni fogja.

  3. Ezt ne hagyd ki: a telepítés végén megnyílik egy Finder-ablak (Alkalmazások/Python 3.14). Kattints duplán az Install Certificates.command fájlra. Felugrik egy terminálablak, és ha a végén azt látod, hogy update complete, bezárhatod.

    Miért kell? E nélkül a Python nem tud biztonságosan letölteni adatot a netről (pl. az Eurostatról), és CERTIFICATE_VERIFY_FAILED hibát kapsz.

  4. Indítsd újra a VS Code-ot, nyiss terminált (a fenti menüsorban Terminal → New Terminal, vagy ⌃ `), és ellenőrizd:

    python3 --version
Python 3.14.8
    Macen python3, nem python a parancs alapból. Ez így normális amúgy, de a kurzus projektjeiben később saját környezetet hozunk létre, ott már a python is működni fog.

Git telepítése és beállítása

⏱ 10 perc

A verziókövető. Ennek nincs saját ablaka vagy alkalmazása: a terminálból és a VS Code-ból használjuk csak.

  1. A git-scm.com/install/windows oldalon kattints a Click here to download linkre.

  2. Futtasd a Git-….exe telepítőt. Sok kérdést tesz fel, majdnem mindenhol jó a Next. Két képernyőn változtass:

    • Choosing the default editor used by Git: a legördülő listából válaszd a Use Visual Studio Code as Git's default editor lehetőséget.
    • Adjusting the name of the initial branch in new repositories: válaszd az Override the default branch name lehetőséget, a mezőben maradjon main.

    A végén Install, majd Finish.

  3. Indítsd újra a VS Code-ot, és add meg a Gitnek a neved és az e-mail-címed. Ezek kerülnek majd minden pillanatképre (commitra). Az idézőjelek közé a sajátodat írd, és használd ugyanazt az e-mail-címet, amivel a GitHubra regisztráltál (én a personalt ajánlom, nem a sulisat):

    git config --global user.name "Tuboly Roland"
git config --global user.email "tuboly.roland.levente@gmail.com"

    Ellenőrzés:

    git --version
git version 2.56.0

  2. Indítsd újra a VS Code-ot, és add meg a Gitnek a neved és az e-mail-címed. Ezek kerülnek majd minden pillanatképre (commitra). Az idézőjelek közé a sajátodat írd, és használd ugyanazt az e-mail-címet, amivel a GitHubra regisztráltál (én a personalt ajánlom, nem a sulisat):

GitHub Copilot bekapcsolása

⏱ 5 perca VS Code-ban, a GitHub-fiókkal

Az AI-asszisztens. A Copilot már benne van a VS Code-ban, csak be kell jelentkezni a GitHub-fiókoddal.

  2. Válaszd a Sign in with GitHub lehetőséget. Megnyílik a böngésző, ott lépj be, és engedélyezd a VS Code-nak a hozzáférést (Authorize). Ha a böngésző megkérdezi, hogy megnyithatja-e a VS Code-ot, engedd.

Gépcsekk: az első Python-scripted

⏱ 5 perc

Ne higgy nekem, ellenőrizd te magad hogy minden működik-e. Ez a rövid script megnézi, hogy minden a helyén van-e. A kurzuson is így dolgozunk majd: nem az számít, hogy valami működőnek tűnik, hanem hogy egy ellenőrző program szerint is jó-e.

  1. Hozz létre egy új mappát, például a Dokumentumok között, ai-kurzus néven. A VS Code-ban a felső menüsorban File → Open Folder…, és válaszd ki ezt a mappát. Ha megkérdezi, megbízol-e a mappa szerzőiben: Yes, I trust the authors.

  2. Bal oldalt, a mappa neve mellett kattints a New File… ikonra (lehajtott csücskű A4-es lap egy + jellel), és nevezd el így: gepcsekk.py. Másold bele ezt a kódot alább, és mentsd el (Ctrl⌘ S):

    """Gépcsekk az első órára: megnézi, hogy a Python, a Git és a netkapcsolat rendben van-e."""
import platform
import shutil
import ssl
import subprocess
import sys
import urllib.error
import urllib.request

eredmenyek = []


def ellenoriz(nev, sikerult, tipp=""):
    """Kiír egy RENDBEN/HIBA sort, és megjegyzi az eredményt."""
    eredmenyek.append(sikerult)
    if sikerult:
        print(f"RENDBEN  {nev}")
    else:
        print(f"HIBA     {nev}\n         -> {tipp}")


ellenoriz(
    f"Python {platform.python_version()}",
    sys.version_info >= (3, 12),
    "Régi a Python. Telepítsd a legújabbat a python.org-ról.",
)

git = shutil.which("git")
ellenoriz("Git telepítve", git is not None,
          "Nem találom a gitet. Telepítsd, aztán indítsd újra a VS Code-ot.")

if git:
    for kulcs, magyarul in [("user.name", "név"), ("user.email", "e-mail")]:
        ertek = subprocess.run([git, "config", "--global", kulcs],
                               capture_output=True, text=True).stdout.strip()
        ellenoriz(f"Git-{magyarul}: {ertek or '(nincs beállítva)'}", bool(ertek),
                  f'Futtasd a terminálban: git config --global {kulcs} "..."')

# A python.org-os macOS-Python tanúsítványok nélkül érkezik; ez itt derül ki.
try:
    urllib.request.urlopen("https://www.python.org", timeout=10)
    ellenoriz("HTTPS-kapcsolat", True)
except urllib.error.URLError as hiba:
    if isinstance(hiba.reason, ssl.SSLCertVerificationError):
        tipp = ("Macen: Finder > Alkalmazások > Python 3.14 mappa, "
                "dupla katt az Install Certificates.command fájlra.")
    else:
        tipp = f"Nincs internet, vagy tűzfal blokkolja. ({hiba.reason})"
    ellenoriz("HTTPS-kapcsolat", False, tipp)

print()
if all(eredmenyek):
    print("Minden RENDBEN. Készen állsz az első órára!")
else:
    print("Van HIBA. Kövesd a tippet, vagy hozd el így az órára, megoldjuk ott.")

  3. Futtasd: kattints a szerkesztő jobb felső sarkában lévő ▷ (Run Python File) gombra. Alul, a terminálban ezt kell látnod:

    RENDBEN  Python 3.14.8
RENDBEN  Git telepítve
RENDBEN  Git-név: Tuboly Roland
RENDBEN  Git-e-mail: tuboly.roland.levente@gmail.com
RENDBEN  HTTPS-kapcsolat

Minden RENDBEN. Készen állsz az első órára!

    Ha valahol HIBA áll, a sor alatt ott a tipp, mit csinálj. Ha nem megy, semmi gond: hozd el a laptopod így, és az óra elején megoldjuk.

Kíváncsi vagy, mit csinál a kód? Jelöld ki az egészet, és kérdezd meg a Copilotot: „Magyarázd el soronként, egyszerűen, mit csinál ez a kód.” Pontosan ezt fogjuk gyakorolni a kurzus elején.

Opcionális, csak ha már van előfizetésed

Claude Code

Az Anthropic AI-asszisztense, amely a Copilothoz hasonlóan a VS Code-ban is tud dolgozni. A kurzus elvégzéséhez nincs rá szükség, és nem kell miatta előfizetni. Ha viszont már van fizetős Claude-előfizetésed (Pro vagy Max), használhatod a Copilot mellett.

Az ingyenes Claude-fiókkal nem működik. A Claude Code-hoz Pro (havi 20 dollár) vagy nagyobb előfizetés, esetleg fizetős API-hozzáférés kell.

  1. A VS Code-ban nyisd meg az Extensions nézetet (Ctrl⌘ ⇧ X), keresd meg a Claude Code bővítményt (kiadó: Anthropic), és telepítsd.

  2. A szerkesztő jobb felső sarkában megjelenik egy kis csillag-szikra ikon. Kattints rá, majd a böngészőben lépj be a Claude-fiókoddal.

  3. Ha a terminálban is használni szeretnéd (ez meg aztán egyáltalán nem kötelező), telepítsd a parancssori változatot is:

    irm https://claude.ai/install.ps1 | iex
    curl -fsSL https://claude.ai/install.sh | bash

    Ez a PowerShell-parancs, a VS Code terminálja alapból PowerShell.

Szabályfájl: a Copilot a projekt AGENTS.md fájlját olvassa, a Claude Code a CLAUDE.md-t. A kurzus sablonjaiban mindkettő benne van, és ugyanazt mondják, így mindegy, melyik asszisztenst használod.

Ha elakadsz

Gyakori hibák

A legtöbb probléma a lenti hibák egyike. Ha egyik sem az, készíts képernyőképet a hibaüzenetről, és küldd el nekem, vagy mutasd meg az első óra előtt/elején.

Windowson a „python” parancs a Microsoft Store-t nyitja meg, vagy nem található Windows

A Windowsnak van egy beépített „python” parancsa, ami a Store-ba irányít, és ez elfedheti az igazit.

Megoldás: Start menü → írd be: alkalmazás-végrehajtási aliasok (angolul: Manage app execution aliases). A listában keresd meg a Python-sorokat: a Python install manager és a Python (default) legyen bekapcsolva, a sima „App Installer · python.exe” ki. Utána zárd be és nyisd meg újra a VS Code-ot.

„… is not recognized” / „command not found”, pedig telepítettem mindkettő

A terminál csak indításkor nézi meg, milyen programok vannak a gépen. Ha telepítés előtt nyitottad meg, nem tud az újról.

Megoldás: zárd be teljesen a VS Code-ot, és nyisd meg újra. Ha még mindig nem megy, indítsd újra a gépet.

CERTIFICATE_VERIFY_FAILED hiba macOS

A python.org-os Python Macen tanúsítványok nélkül érkezik, ezért nem tud biztonságos (https) kapcsolatot nyitni.

Megoldás: Finder → Alkalmazások → Python 3.14 mappa → dupla kattintás az Install Certificates.command fájlra.

„python: command not found” Macen macOS

Macen a parancs neve python3. A python a kurzus saját projektkörnyezeteiben fog működni, ezt a 0. órán állítjuk be.

„running scripts is disabled on this system” Windows

A PowerShell alapból tiltja a scriptek futtatását. A Claude Code telepítőjénél vagy a 0. órán a saját környezet bekapcsolásánál jöhet elő.

Megoldás: futtasd ezt egyszer a terminálban, majd nyiss új terminált:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
Nem látom a Copilot ikonját, vagy a bejelentkezés nem fejeződik be mindkettő

Frissítsd a VS Code-ot (bal alul fogaskerék → Check for Updates…), és indítsd újra. Ha a böngészőben sikeres volt a belépés, de a VS Code nem tud róla, a felugró ablakban válaszd a Megnyitás a Visual Studio Code-ban lehetőséget.

Elutasították a hallgatói kérelmemet GitHub

Nem gond, újra lehet próbálni. A leggyakoribb okok: elmosódott vagy levágott fotó, VPN, kikapcsolt helymeghatározás, vagy eltérő név a GitHub-profilban és az igazoláson. Javítsd ki, és küldd be újra. A kurzus a Copilot Free csomaggal is elindul.

Régi vagy gyenge a laptopom. Gond lesz? mindkettő

Valószínűleg nem. Az AI-modellek nem a te gépeden futnak, hanem a szolgáltató szerverein. A kurzushoz Windows 10/11 vagy macOS 12+ kell, és nagyjából 3 GB szabad hely.

Szótár

Szavak, amiket hallani fogsz

terminál
Szöveges ablak, ahová parancsokat gépelsz ahelyett, hogy ezeket az egereddel adnád a gépednek. A VS Code alján is van egy.
parancs
Egy sor a terminálban, pl. python --version. Enterrel futtatod.
mappa / könyvtár / directory
Ugyanaz. A programozók inkább könyvtárnak (directory) mondják.
PATH
Azoknak a helyeknek a listája, ahol a terminál a programokat keresi. A „not found” hiba általában azt jelenti, hogy valami nincs rajta.
bővítmény (extension)
Kiegészítő a VS Code-hoz, pl. a Python-bővítmény.
script
Egy .py fájl, amit a Python elejétől a végéig lefuttat (lehet más kiterjesztés is, a .py egy Python-script).
repó (repository)
Egy Git által követett projektmappa, a teljes előzményeivel együtt.
